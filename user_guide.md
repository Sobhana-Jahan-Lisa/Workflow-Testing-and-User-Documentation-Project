# User Guide

## Graduate Application Portal Workflow Simulation

This guide explains how to use the simulated graduate application portal.

## Step 1: Applicant Information

Enter the following information:

- First name
- Last name
- Email address
- Program
- Term
- Applicant type

All fields are required. The system checks whether the email address has a valid format.

## Step 2: Required Document Checklist

Select the documents that have been received:

- Transcript
- Statement of Purpose
- Recommendation Letters
- CV or Resume
- English Proficiency

For international applicants, English Proficiency is required. For domestic applicants, this document is not required in this simulation.

## Step 3: Review Application

The review page shows a summary of applicant information and document status. Users should verify that all information is correct before submitting.

## Step 4: Confirmation

After submission, the system displays a confirmation message and a simulated confirmation ID.

## Help Desk Support Panel

The support panel allows users to create a support note for workflow-related issues. To create a support note:

1. Select an issue type.
2. Enter an issue description.
3. Click **Create Support Note**.
4. Review the generated ticket ID and suggested next step.

## Common User Mistakes

- Leaving required fields empty
- Entering an invalid email address
- Forgetting to select required documents
- International applicants missing English Proficiency
- Trying to create a support note without a description
