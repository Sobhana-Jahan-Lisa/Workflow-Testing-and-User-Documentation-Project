# Process Improvement Notes

## Goal

The goal of this review is to identify ways to improve the clarity, reliability, usability, and supportability of the simulated graduate application workflow.

## Improvement 1: Add Field-Level Help Text

### Observation

Users may not understand the required format for some fields.

### Recommendation

Add short help text under important fields such as email, program, term, and applicant type.

## Improvement 2: Add Real-Time Validation

### Observation

Validation messages currently appear after the user clicks the next-step button.

### Recommendation

Show validation feedback while the user is typing or selecting options.

## Improvement 3: Clarify Document Requirements

### Observation

International applicants have an extra requirement for English Proficiency.

### Recommendation

Display conditional instructions when the user selects International as the applicant type.

## Improvement 4: Add Save Progress Feature

### Observation

Users may need to leave the workflow and return later.

### Recommendation

Add local storage or backend persistence to save partially completed applications.

## Improvement 5: Improve Help Desk Categorization

### Observation

Support requests could be better organized.

### Recommendation

Add fields for priority, affected workflow step, browser, and screenshot/evidence.

## Improvement 6: Add Administrative Dashboard

### Observation

Staff may need to view submitted applications and support tickets.

### Recommendation

Add a dashboard to summarize submitted applications, incomplete records, and support issues.

## Improvement 7: Add Accessibility Checks

### Observation

Workflow tools should support accessibility.

### Recommendation

Add keyboard navigation testing, screen-reader labels, and color-contrast review.
