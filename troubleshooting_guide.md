# Troubleshooting Guide

## Issue 1: User cannot continue from Applicant Information

### Possible Cause

One or more required fields are empty, or the email address is invalid.

### Suggested Resolution

Ask the user to check:

- First name
- Last name
- Email address
- Program
- Term
- Applicant type

The email address should follow a format similar to `applicant@example.edu`.

## Issue 2: User cannot continue from Document Checklist

### Possible Cause

One or more required documents are missing.

### Suggested Resolution

Check whether the following are selected:

- Transcript
- Statement of Purpose
- Recommendation Letters
- CV or Resume

For international applicants, also check:

- English Proficiency

## Issue 3: Review summary does not appear

### Possible Cause

The applicant or document step may not have been completed correctly.

### Suggested Resolution

Return to earlier workflow steps and confirm all required information was entered.

## Issue 4: Support note is not created

### Possible Cause

The issue description field is empty.

### Suggested Resolution

Ask the user to enter a short description of the problem before creating the support note.

## Issue 5: User wants to restart the workflow

### Suggested Resolution

After submission, click **Start New Application**. This resets the form and returns the user to the first step.

## Escalation Guidance

Escalate the issue if:

- The same issue is reported repeatedly
- A validation rule blocks valid users
- A workflow step is confusing to many users
- Data shown on the review page does not match user input
- The confirmation message does not appear after submission
